# Research site of Javier Argota Sánchez-Vaquerizo

Static one-page site: `index.html`, `styles.css`, `script.js`, `assets/`, `data/publications.json`.
Published with GitHub Pages from the root of the `main` branch.

- Publication list, filters and the hero chart are generated from the CV source and written to `index.html`.
- Figures in `assets/img/` come from the authors' own papers and projects. Reuse terms of individual figures are being confirmed; do not reuse them without checking.
- Fonts fall back to Helvetica Neue, Helvetica, Arial. To use Geist, add `Geist-Variable.woff2` to `assets/fonts/`.
